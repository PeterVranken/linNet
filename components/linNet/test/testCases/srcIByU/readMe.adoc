Introduction of the voltage controlled current source:

The input circuit is a simple voltage divider. The divided input
voltage is the control voltage of the current source in the second
circuit.

A voltage controlled current source and a resistive load form a
second circuit. Both circuits share the same ground.

The expected result is:

U~Kout~ = -I~0~\*R~out~, I~0~=k*R~2~/(R~1~+R~2~+R~3~) U~in~,
U~Kout~=-k*(R~2~*R~out~)/(R~1~+R~2~+R~3~)*U~in~. Note k has the unit 1/Ohm.

Please compare with the link:srcIByU.log[calculated result^]: The netlist
specifies the ratios of the values of the different resistors. This leads
to a further simplification of the expected result.

See link:srcIByU.cnl[netlist file^] for more details of the circuits.
