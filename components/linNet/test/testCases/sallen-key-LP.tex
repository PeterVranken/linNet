This documernt presents a circuit that implements the Sallen-Key filter.
The chosen configuration is a low-pass of second order. The schematics of
the filter is shown in figure~\ref{figLPSallenKey} on page
\pageref{figLPSallenKey} and the netlist for computing the transfer
function is shown in listing~\ref{lstNetListSallenKeyLP}.
