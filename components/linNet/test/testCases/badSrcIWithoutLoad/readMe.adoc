A current source has no load impedance connected. This leads to an linear
equation system with zero determinant. linNet doesn't abort the
calculation but ends with an infinite node potential.

The link:badSrcIWithoutLoad/allDependents.m[Octave script^] is still
generated but the transfer function object it creates, would be bad and
make Octave fail when used. linNet has placed an explaining error message
in the script to avoid a hard to understand, generic, nonspecific Octave
error message.
