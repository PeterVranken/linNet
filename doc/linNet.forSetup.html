linNet, the Software for symbolic Analysis of linear Electronic Circuits

Peter Vranken
P. Vranken

linNet is an application for computing the transfer function of linear electronic circuits. The computation is performed symbolically rather than numerically, and the result is a formula rather than a number or a series of numbers. The resulting formula is the Laplace transform describing the dependencies of the voltages and currents in the circuit on the input voltages and currents.

Figure 1. Simple example of a linear electronic circuit

A linear electronic circuit is a combination of the supported basic devices listed in Table 1. The circuit is input to linNet. The representation of the circuit is a list of devices with connectivity information. The interconnections are expressed by references to nodes, where a node is a point in the circuit to which normally at least two devices are connected. This leads to a simple formal syntax, the circuit network list, or simply netlist. This list can be created and maintained with a text editor; there is no graphical interface for editing a circuit.

The computed formulas are printed to the console and to the application log file and can be used for further investigation, publications, or didactic purposes.

To make the application somewhat more attractive, it also exports the computed formulas as GNU Octave or MATLAB script code. Numeric evaluation then becomes a simple one-line command in Octave. The formulas are exported as LTI transfer function objects so that the complete set of analysis functions from the Octave Control package can be applied directly. This ranges from simple transfer function plotting to stability analysis and the computation of system responses to arbitrary inputs.

Please refer to Figure 1 for an example of how linNet works. This is a simple RLC circuit with a second-order transfer function. It can be represented by the following circuit netlist:

U Uin in  gnd
L L   in  K1
C C   K1  out
R R   out gnd
PLOT G U_out U_in

If this netlist is stored in file rlc.cnl, we can run linNet:

linNet -o rlc.cnl

This would yield the output:

User-defined result G (Bode plot):
The dependency of U_out on U_in:
  U_out(s) = N_U_out_U_in(s)/D_U_out_U_in(s) * U_in(s), with
    N_U_out_U_in(s) = R*C * s
    D_U_out_U_in(s) = L*C * s^2
                      +R*C * s
                      +1

The command line switch -o made linNet generate Octave script G.m. Going to Octave and typing G to plot the transfer function gives us Figure 2. For this plot, Octave used default values for R, L and C. Additional plots or plots with modified device values are then a matter of single commands in Octave.

Figure 2. Octave plot using the linNet generated LTI object

For detailed information about linNet, including installation instructions, the netlist syntax, the Octave interface, and the mathematical concepts behind the program, please refer to the user guide, linNet-userGuide.pdf.

linNet means "linear network". It is based on a symbolic solver for linear equation systems. There is no way to model non-linear effects such as noise, voltage or current limits, non-linear distortions, or switching operations. All of these effects play an important role in real electronic circuits, and many circuits even use these effects as their principle of operation. You will not find linNet helpful for the investigation of such effects or circuits. There are many numeric circuit simulation tools that are capable of this, first and foremost the popular open-source tool SPICE and its many derivatives. linNet is conceptually not a competitor to these tools, although it can behave somewhat similarly when using Octave as a numeric post-processor. linNet is not the worse SPICE; linNet is different.
