= linNet - The Software for symbolic Analysis of linear Electronic Circuits

The installation of linNet is explained in the user guide, Chapter 2 on page 12.

Chapters 3 and 4 of the user guide explain the usage of the application.

The user guide is locally available as file
`<linNetInstallDir>/doc/linNet-userGuide.pdf` or online at GitHub as
link:https://github.com/PeterVranken/linNet/blob/main/doc/userGuide/linNet-userGuide.pdf[^].

== Release notes:

=== Revision 1.1, 2026

- Revision of the user guide with several clarifications and modifications
  related to the new hosting platform GitHub and the modifications in the
  user interface.
- Careful refinement of the source code with a few user interface
  improvements.
- Source code modernization to ensure compatibility with current compiler
  releases.
- A few minor bug fixes, all related to error paths with wrong or
  misleading error messages.
- This version of linNet is hosted on
  link:https://github.com/PeterVranken/linNet/[GitHub^].

=== Revision 1.0.1

- No functional changes but the sources and makefiles are now compatible
  with Linux. The build has been tested with Fedora 18. The compiled
  software has not been tested under Linux besides some basic tests that
  it is running with the distributed test cases
- The distributed packages now contain the Linux binaries, too. The
  documentation has been updated accordingly
- The distributed packages contain some more out of the original test
  cases
- This version of linNet is still available on
  link:https://sourceforge.net/projects/linnet-svn/[SourceForge^].
  
=== Revision 1.0

- First release of linNet on Google Code in 2013. After Google Code was
  shut down two years later, linNet moved to SourceForge.

=== LIN_NETZ.TTP

- Release of ancestor of linNet on Atari ST in 1992. The original source
  code and the executable files are still archived in
  link:https://github.com/PeterVranken/linNet/tree/LIN_NETZ-originalCodeBaseFrom1991/1992-originalSource[GitHub^].
